# Application Deadlines View

**Product Management Work Sample | InsiderOne AI**

## Overview

This product specification proposes an Application Deadlines View that helps students manage important dates across multiple job applications.

The proposed solution extends the existing Today experience rather than introducing another application tracker.

## Problem Statement

Students managing multiple applications may struggle to track application closing dates, assessments, work samples, interviews, and follow-ups across different platforms.

This proposal explores how these deadlines can be brought together into one actionable view.

## Proposed MVP

The first version focuses on:

- Grouping deadlines into Overdue, Today, and Upcoming.
- Categorising different application-related deadlines.
- Linking tasks to existing applications in My Pipeline.
- Allowing students to add or edit missing dates.
- Marking actionable tasks as complete.

## Success Measurement

Primary metric: On-time task completion rate.

Additional considerations include date accuracy, missing-date rate, task-entry completion, repeat usage, and missed-deadline guardrails.

## Validation Approach

The proposal recommends moderated usability testing followed by a small, time-limited pilot before wider release.
